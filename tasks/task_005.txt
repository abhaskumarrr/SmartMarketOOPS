# Task ID: 5
# Title: API Key Management
# Status: done
# Dependencies: 3
# Priority: medium
# Description: Implement secure storage and management of exchange API keys
# Details:
Build a secure API key management system with:
1. Encrypted storage of API credentials
2. UI for managing Delta Exchange API keys
3. Scoped access controls
4. Environment switching between testnet and mainnet
5. Key rotation and revocation capabilities

The system should use strong encryption for API key storage and provide a clear UI for users to manage their credentials. It should include safeguards against accidental mainnet usage and support key rotation for security.

# Test Strategy:
1. Verify encryption/decryption of API keys
2. Test key validation against exchange
3. Security audit of storage mechanism
4. Test environment switching logic
5. Verify key revocation functionality
