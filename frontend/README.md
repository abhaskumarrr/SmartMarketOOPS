# Frontend Service

This directory contains the Next.js frontend for the SmartMarketOOPS project.

## Overview

The frontend provides the user interface for the trading dashboard. It allows users to:
- View real-time market data and charts.
- Monitor their portfolio and open positions.
- Provide feedback on the AI agent's trades to guide its learning.

## Getting Started

This service is started as part of the unified startup script in the root directory. To run it independently:

```bash
# From the frontend/ directory
npm run dev
```

The dashboard will be available at [http://localhost:3000](http://localhost:3000).

For more detailed information on the architecture and project structure, please see the main documentation in the `docs/` directory at the root of the project.
